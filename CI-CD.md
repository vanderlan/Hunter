# CI/CD Workflow Summary

## ?? Automated Workflows

### 1. Build and Test (`build.yml`)

**Triggers:**
- Push to `master` branch
- Pull requests

**Steps:**
1. Setup .NET 10 environment
2. Setup PostgreSQL and Elasticsearch services
3. Run database migrations
4. Build .NET solution
5. Run tests with code coverage
6. Setup Node.js 18
7. Install frontend dependencies
8. Build Angular frontend
9. Upload coverage to Codecov

### 2. Deploy (`deploy.yml`)

**Triggers:**
- Push to `master` branch
- Version tags (`v*.*.*`)

**Steps:**

#### Job 1: Build Backend Docker Image
- Checkout code
- Generate Docker metadata (tags)
- Setup QEMU and Buildx
- Login to DockerHub
- Build and push `vanderlangs/hunter-api:latest`

#### Job 2: Build Frontend Docker Image
- Checkout code
- Generate Docker metadata (tags)
- Setup QEMU and Buildx
- Login to DockerHub
- Build and push `vanderlangs/hunter-frontend:latest`

#### Job 3: Deploy to Production
- SSH into production server
- Navigate to `~/projects/hunter`
- Execute `deploy.sh` script

#### Job 4: Health Check
- Wait 30 seconds for services to start
- Check API health: `https://hunter.geminicode.com.br/api/health`
- Check Frontend: `https://hunter.geminicode.com.br/`
- Retry up to 5 times with 10s delay

## ?? Docker Images

### Backend API
- **Image**: `vanderlangs/hunter-api:latest`
- **Base**: `mcr.microsoft.com/dotnet/aspnet:10.0`
- **Port**: 80 (mapped to 5010 on host)
- **Health**: `/api/health`

### Frontend
- **Image**: `vanderlangs/hunter-frontend:latest`
- **Base**: `nginx:alpine`
- **Port**: 80 (mapped to 5200 on host)
- **Tech**: Angular 17 + Nginx

## ?? Required GitHub Secrets

### Docker Registry
- `DOCKERHUB_USERNAME` - DockerHub username
- `DOCKERHUB_TOKEN` - DockerHub access token

### Production Server
- `HUNTER_PROD_HOST` - Server IP or domain
- `HUNTER_PROD_USER` - SSH username
- `HUNTER_PROD_PASSWORD` - SSH password
- `HUNTER_PROD_SSH_PORT` - SSH port (usually 22)

### Optional (for future use)
- `CODECOV_TOKEN` - Code coverage reporting

## ??? Troubleshooting

### Build Failed
1. Check GitHub Actions logs
2. Verify .NET 10 SDK compatibility
3. Check test failures
4. Verify frontend build

### Deployment Failed
1. Check SSH connection
2. Verify server has Docker
3. Check deploy.sh permissions
4. Verify .env file exists

### Health Check Failed
1. Check service logs
2. Verify ports are open
3. Check nginx configuration
4. Verify database connection
