Summary:
The Senior Site Reliability Engineer (SRE) will design, implement, and operate reliable, secure, and automated deployment platforms that enable rapid delivery of services on Microsoft Azure. This role is critical to ensuring availability, scalability, and observability for .NET Core applications and related services through CI/CD, containerization, infrastructure as code, and robust monitoring.
You will work across development and operations teams to build repeatable pipelines, manage containerized workloads, and apply platform engineering practices to improve reliability and security. This position offers the opportunity to lead cloud-native infrastructure work using Docker, Kubernetes, Terraform, Azure services, and a broad observability and security toolset.

Responsibilities:
Design and implement CI/CD pipelines to automate build, test, and deployment processes.Build and operate containerized workloads using Docker and Kubernetes.Define and manage infrastructure as code using Terraform for Azure deployments.Configure and maintain Microsoft Azure resources and platform tooling.Implement monitoring and alerting with Prometheus, Grafana, and Azure Monitor.Manage secure API access and authentication using OAuth 2.0 and API gateway configuration.Oversee SSL/TLS certificate management and related operational procedures.Automate system configuration and deployments with Ansible and Puppet.Administer Windows Server environments and IIS for application hosting.Deploy and host .NET Core applications and manage related runtime dependencies.Develop automation and operational scripts using PowerShell and Git-based workflows.Analyze logs and incidents using ELK Stack and Splunk to drive reliability improvements.Apply security scanning tools, configure network security and firewall rules to protect services.

Requirements:
5+ years of experience in site reliability, platform engineering, or DevOps roles.3+ years of hands-on experience building and operating CI/CD pipelines.Proven experience with Docker and Kubernetes in production environments.Strong experience with Terraform and managing Azure infrastructure.Demonstrated experience administering Microsoft Azure services and Azure DevOps.Experience with Prometheus, Grafana, and Azure Monitor for observability and alerting.Practical knowledge of OAuth 2.0 and SSL/TLS certificate management.Experience automating configuration with Ansible and/or Puppet.Experience administering Windows Server and IIS for .NET Core application hosting.Proficiency with Git and PowerShell for automation and version control.Experience working with ELK Stack and Splunk for log aggregation and analysis.Familiarity applying security scanning tools, configuring network security, and firewall management.Strong Experience with API gateway configuration and platform engineering practices.Knowledge of Microsoft Entra for identity and access management.
