Hunter Design Language

Every value below is read live from styles/_tokens.scss. Build new screens from these tokens — never from raw hex.

Surfaces

A tonal ramp. Each step is an elevation plane, not a flat grey.

@for (s of surfaces; track s.token) {
{{ s.name }} {{ s.token }}
}

Brand

@for (s of brand; track s.token) {
{{ s.name }} {{ s.token }}
}
brand-gradient --hunter-brand-gradient

The gradient is the single brand ramp — sidebar, login and the email header all reference it. Do not hand-roll another one.

Status palette

Chips, badges, callouts and toasts all draw from these. One meaning, one colour, everywhere.

@for (tone of statuses; track tone) {
{{ tone }} --hunter-{{ tone }}-*
}

Badges

@for (tone of statuses; track tone) { {{ tone }} } neutral

Typography

Inter across the whole product — UI chrome and body copy alike.

@for (t of typeScale; track t.cls) {
{{ t.label }} {{ t.sample }}
}

Space scale

4px base. Use the token, not a magic number.

@for (n of spacing; track n) {
--hunter-space-{{ n }}
}

Shape & elevation

@for (r of radii; track r) {
{{ r }}
}
@for (s of shadows; track s) {
shadow-{{ s }}
}
