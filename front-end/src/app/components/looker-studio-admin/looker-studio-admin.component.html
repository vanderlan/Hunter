help_outline How to get the curl command
  1. Open Looker Studio and login with your company email
  2. Navigate to the "Taller Open Positions and Priorities" report
  3. Open browser DevTools (F12) and go to the Network tab
  4. Refresh the page (F5 or Ctrl+R) to capture the data request
  5. Find the request to batchedDataV2 in the Network tab (should show POST, 200 OK)
  6. Right-click on the request → Copy → Copy as cURL (bash) ✅
  7. Paste the entire curl command in the text area below
info
Important: You MUST use "Copy as cURL (bash)" format. Copy the batchedDataV2 request (POST, 200 OK) that happens when you refresh the page. This is the request that loads the report data, NOT the export button.
