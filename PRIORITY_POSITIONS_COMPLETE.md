## ?? How to Use

### For Users

**1. Admin: Sync Priorities from Looker Studio**
```
1. Go to Admin ? Looker Studio
2. Refresh Looker Studio page in Chrome
3. Copy batchedDataV2 request (F12 ? Network)
4. Paste curl command in Hunter
5. Click "Sync Priorities Now"
6. ? Done! Priorities updated
```

**2. Recruiter: See Priorities**
```
1. Go to Job Positions
   ? See priority badges in table
```

## ?? Configuration

### Production Deployment

**1. Update appsettings.Production.json:**
```json
{
  "LookerStudio": {
    "BatchDataUrl": "https://lookerstudio.google.com/u/0/batchedDataV2",
    "RequestTimeoutSeconds": 30,
    "EncryptionKey": "YOUR_SECURE_32_CHAR_KEY_HERE"
  }
}
```

**2. Environment Variables (Optional):**
```bash
LookerStudio__EncryptionKey=YOUR_KEY
LookerStudio__RequestTimeoutSeconds=30
```

**3. Database Migration:**
```bash
# Already applied!
dotnet ef database update
```
